# מאמר מוסגר

משחק חידות יומי בעברית (RTL), בהשראת ז׳אנר חידות הסוגריים המקוננות. מפענחים משפט חבוי, סוגר אחר סוגר, מהעלה הפנימי החוצה. הפרויקט נבנה כפיצ׳ר יומי פוטנציאלי לאתרי תוכן ישראליים.

## איך זה עובד?

פסקת טקסט שבה חלק מהמילים הוחלפו ברמזים בתוך סוגריים מרובעים. הרמזים יכולים להיות **מקוננים** זה בתוך זה ויוצרים מבנה עץ. השחקן פותר תחילה את העלים הפנימיים, וכל פתרון חושף טקסט חדש שעשוי להכיל רמזים נוספים — עד שהמשפט המלא נחשף.

**דוגמה:**

```
ב[שר של [חיה שנוהמת]] טעים
```

1. `[חיה שנוהמת]` ← **אריה** (עלה — פתיר מיד)
2. עכשיו הסוגר ההורה נפתח: `[שר של אריה]` ← **בשר**
3. המשפט המלא: **״בבשר טעים״**

## כללים מהותיים

| כלל | תיאור |
|------|--------|
| פתרון מהעלים | רק סוגר ללא ילדים לא־פתורים מקבל קלט |
| עצמאות אחים | סוגרים תחת אותו הורה ניתנים לפתרון בכל סדר |
| נעילת ההורה | הורה נעול עד שכל ילדיו נפתרו |
| תגובת שרשרת | פתרון עלה עשוי להפוך את ההורה שלו לעלה פתיר |

### ניקוד

- כל חידה מתחילה ב־100 נקודות.
- ניחוש שגוי: **‎-2**
- הצצה (אות ראשונה): **‎-5**
- חשיפה מלאה: **‎-20**
- דרגות סיום: **תייר** ← **ראש עיר** ← **מלך העיר** (Kingmaker — פתרון מושלם).

## למה עברית?

- מבנה השורש העברי (3 אותיות) מתאים באופן טבעי לרמזים מקוננים.
- שוק חזק של משחקי מילים בעברית (תשבצים, וורדל׳ה, Meduyeket).
- אין עדיין מימוש עברי לז׳אנר.

## טכנולוגיות

- **Next.js 14** (App Router) + **React 18** + **TypeScript**
- **Tailwind CSS** עם תמיכה מלאה ב־RTL ובמאפייני CSS לוגיים
- **Vitest** לבדיקות יחידה של מנוע החידה

## הרצה מקומית

```bash
npm install
npm run dev          # פיתוח: http://localhost:3000
npm run build        # build לפרודקשן
npm run start        # הרצת ה־build
npm run lint         # בדיקות lint
npm test             # הרצת בדיקות (Vitest)
npm run test:watch   # בדיקות במצב watch
```

## מבנה הפרויקט

```
app/
  page.tsx           — דף החידה היומית
  admin/             — לוח ניהול: לוח שנה, ארכיון, בונה חידות
  api/admin/         — נקודות קצה ניהוליות
components/
  GameContainer.tsx  — מצב המשחק וניהול קלט
  PuzzleBoard.tsx    — רינדור עץ הסוגריים
  AnswerBank.tsx, HUD.tsx, ControlsBar.tsx, EndGameScreen.tsx
  admin/             — רכיבי הבונה והעורך
lib/puzzle/
  parser.ts          — פירוק מחרוזת סוגריים לעץ
  engine.ts          — לוגיקת מצב (נעילה, שרשרת פתרונות)
  build.ts           — בניית חידה מ־specs
  scoring.ts         — חישוב ניקוד ודרגות
  hebrew.ts          — נירמול טקסט עברי, ניקוד, סופיות
  share.ts           — פורמט שיתוף בסגנון Wordle
  validate.ts        — בדיקת תקינות חידה
data/puzzles.json    — מאגר החידות לפי תאריך
docs/                — מסמך התכנון המלא ומחקר עיצוב
```

## חידות ולוח ניהול

- חידות מאוחסנות ב־[data/puzzles.json](data/puzzles.json) לפי `date` (YYYY-MM-DD, לפי שעון ישראל).
- [/admin](app/admin/page.tsx) — בונה חידות עם תצוגה מקדימה.
- [/admin/calendar](app/admin/calendar/) — לוח שנה עם תאים מלאים/ריקים; קליק על תאריך פותח את הבונה ממולא־מראש.
- [/admin/archive](app/admin/archive/) — ארכיון חידות לעריכה.
